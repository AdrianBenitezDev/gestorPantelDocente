Texto verificación OAuth (Gmail gmail.readonly)

No enviamos correos, no modificamos el buzón y no eliminamos mensajes. El acceso ocurre solo por acción directa del usuario, aplicando principio de mínimo privilegio y sin uso publicitario ni cesión de datos a terceros.

Texto verificación OAuth (Sheets spreadsheets)
La aplicación solicita https://www.googleapis.com/auth/spreadsheets solo cuando el usuario realiza acciones que requieren escribir en una planilla. Tras extraer datos de Gmail, el usuario valida filas y decide guardar o generar archivo. En ese momento la app crea/actualiza una hoja de cálculo para registrar encabezado y filas procesadas. Sin este permiso, la funcionalidad principal de automatización no puede completarse y el usuario debería cargar datos manualmente. El permiso no se solicita al inicio para todas las acciones, sino de forma incremental cuando la operación lo necesita. El acceso se limita a la ejecución solicitada por el usuario y no se utiliza para finalidades distintas al servicio.

Texto verificación OAuth (Drive drive y drive.readonly)
La app usa permisos de Drive de forma acotada según el flujo. drive.readonly se utiliza cuando el proceso PAC debe leer archivos enlazados desde correos (por ejemplo documentos fuente en Drive). drive se solicita únicamente cuando el usuario decide guardar/descargar el resultado final: se crea una copia de plantilla, se completa con datos extraídos y se entrega la planilla resultante al usuario. En descarga, la copia puede eliminarse luego de exportar el archivo. No exploramos Drive de forma masiva ni accedemos a archivos ajenos al flujo solicitado. Todos los accesos se disparan por acción explícita del usuario y bajo principio de mínimo privilegio.
