Politica de Privacidad y Condiciones de Uso

Este documento describe como se recopilan, usan y protegen los datos en la aplicacion PanelDocente (en adelante, "la Aplicacion").

Ultima actualizacion: 13 de marzo de 2026

1. Responsable del tratamiento

Responsable: Administrador de PanelDocente
Contacto: artbenitezdev@gmail.com

2. Datos que se procesan

  • Datos de cuenta para autenticacion (nombre, correo y UID de Google/Firebase).
  • Consultas ingresadas por el usuario, como la query de Gmail.
  • Datos de correos de Gmail necesarios para el flujo PAC (asunto, remitente, fecha, contenido y adjuntos relevantes).
  • Datos de planillas de Google Sheets indicadas por el usuario.
  • Datos necesarios para crear o guardar archivos en Google Drive cuando el usuario lo solicita.
  • Datos operativos y tecnicos para seguridad, auditoria y diagnostico de errores.

3. Finalidad del tratamiento

  • Permitir el acceso y uso de la Aplicacion.
  • Ejecutar procesos de lectura y extraccion de datos para generar salidas PAC.
  • Guardar resultados en Google Drive y/o Google Sheets segun accion del usuario.
  • Mejorar estabilidad, trazabilidad y seguridad del servicio.

4. Base legal y consentimiento

El tratamiento se basa en el consentimiento del usuario al iniciar sesion y autorizar permisos de Google, y en la necesidad de ejecutar las funciones solicitadas dentro de la Aplicacion.

5. Uso de APIs de Google

Cuando el usuario otorga permisos, la Aplicacion accede solo a los alcances autorizados (por ejemplo Gmail, Sheets y Drive) para ejecutar funcionalidades solicitadas.

La Aplicacion no utiliza datos de Google para publicidad, perfilado comercial ni venta a terceros. El uso y transferencia de datos obtenidos de APIs de Google se limita a las funciones declaradas y se ajusta a la politica de datos de usuario de servicios API de Google.

6. Almacenamiento local en el navegador

La Aplicacion puede guardar informacion en localStorage e IndexedDB para mejorar la experiencia (por ejemplo, mantener la ultima query utilizada). Este almacenamiento se realiza en el dispositivo del usuario.

7. Comparticion de datos

No se venden datos personales. Solo se comparten con proveedores de infraestructura estrictamente necesarios para operar el servicio (por ejemplo Firebase/Google Cloud) y dentro de los limites de esta politica y la normativa aplicable.

8. Conservacion de la informacion

Los datos se conservan por el tiempo necesario para cumplir la finalidad operativa y obligaciones legales o de seguridad. El usuario puede solicitar revision o eliminacion de datos de acuerdo con la normativa aplicable.

9. Seguridad

Se aplican medidas tecnicas y organizativas razonables para proteger la informacion frente a accesos no autorizados, perdida o alteracion.

10. Derechos del titular de datos

El usuario puede solicitar acceso, rectificacion, actualizacion o supresion de sus datos, asi como revocar consentimientos otorgados, enviando un correo al contacto indicado.

Para usuarios en Argentina, esta politica se interpreta conforme a la Ley 25.326 y normas complementarias, en la medida que resulten aplicables.

11. Condiciones de uso

  • El usuario es responsable del uso de su cuenta y de la informacion que procesa.
  • No esta permitido utilizar la Aplicacion para actividades ilegales o no autorizadas.
  • La Aplicacion puede incorporar cambios funcionales o de seguridad sin aviso previo.
  • El uso continuado de la Aplicacion implica aceptacion de estas condiciones.

12. Cambios en esta politica

Esta politica puede actualizarse para reflejar cambios legales, tecnicos o funcionales. La version vigente sera siempre la publicada en esta pagina, con su fecha de actualizacion.
